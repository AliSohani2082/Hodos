# ALI-49 funded run plan (before new generation)

The approved cap for **new** OpenRouter spend is $19.00. The previous smoke and reduced pilot cost $3.24134741 and are outside this new approval. The independent account-credit stop point is `total_usage = 7.3976 + 19.00 = 26.3976`; the account reported 7.39760814 before this run. The runner reserves each request before sending it, checks account usage before every call and during streams, and stops when either bound disallows a call.

The 36-generation pilot measured $0.20547778 per Opus generation, $0.06112448 per Sonnet generation and $0.00350954 per Haiku generation, including repairs. Scaling those rates to 36 tasks × 2 syntax arms × 1 sample gives **$19.45** for three models, or **$19.20** for the two primary models, before safety margin or Q1 judging. Three samples and Q1 judging are outside this budget. The old 648-generation design is quoted at $58.34 generation plus an unmeasured $31.10 judge assumption in the pilot report.

The first phase uses 30 tasks × 2 arms × Opus and Sonnet × 1 sample = 120 generations. It keeps all six adversarial tasks, and omits one base task from each domain (`math-s1`, `programming-s2`, `chess-s3`, `language-s4`, `history-s5`, `science-s1`), so every domain and each of the five lesson shapes remain represented. Its pilot-scaled generation quote is **$16.00**, leaving about **18.8% headroom** under $19 for variation and repairs. If actual spend permits, the runner can resume with `--tasks all` to add omitted task pairs while preserving the same cap and account baseline. A cap stop is expected to leave some cells unrun; no unpaired arm will be intentionally scheduled.

Haiku is omitted because it is informational under §8.5 and the primary models are needed to assess K1–K6. The judge will be run only if the final generation spend leaves enough budget for a complete, balanced Q1 comparison. The 30-pair Q2 blind check needs a human; its export requires no API spend and does not block the run.
